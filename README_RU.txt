J.A.R.V.I.S. — САЙТ AI-ПОМОЩНИКА

ВАЖНО
Это проект сайта, а не готовый публичный адрес. Чтобы сайт отвечал как ИИ, нужно разместить его на хостинге и добавить OpenAI API key на сервере. Ключ НЕ вставляй в public/app.js или index.html и не отправляй в чат.

КАК ЗАПУСТИТЬ НА ХОСТИНГЕ
1. Загрузи содержимое ZIP в GitHub-репозиторий.
2. Создай новый Web Service на хостинге, который поддерживает Node.js (например, Render).
3. Build command: npm install
4. Start command: npm start
5. В Environment Variables добавь:
   OPENAI_API_KEY = твой секретный API-ключ
   OPENAI_MODEL = gpt-4.1-mini (необязательно)
6. После публикации открой выданный хостингом HTTPS-адрес.

API KEY
- Создаётся отдельно в платформе OpenAI API.
- API оплачивается отдельно от подписки ChatGPT; проверь цены и лимиты перед включением.
- Не вставляй ключ в HTML/JS на клиенте и не публикуй его в GitHub.
- Если не хочешь подключать платный API, сайт можно использовать как красивую оболочку, но ответы ИИ работать не будут.

ГОЛОС
- Голосовой ввод зависит от поддержки браузера и разрешения микрофона; лучше Chrome по HTTPS.
- Озвучивание использует голоса, доступные в системе/браузере. Это не точная копия голоса JARVIS из фильма.

ЧТО УЖЕ ЕСТЬ
- адаптивный интерфейс в sci-fi стиле;
- чат с историей текущего сеанса;
- отправка сообщений на серверный endpoint /api/chat;
- голосовой ввод и озвучивание ответов;
- кнопка очистки диалога.

ПРОЕКТ
public/index.html — структура сайта
public/style.css — оформление
public/app.js — чат и голосовые функции
server.js — безопасный серверный прокси для API
